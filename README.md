# Sistema-de-riego-automatizado
Para este proyecto de diseño un sistema capaz de monitorear todas las variables que intervienen en el  proceso y establecer sistemas de lazo cerrado que permitan un control automático, para ello se inició investigando los procesos de riego y las necesidades de distintas plantas, luego se identificaron las principales variables que intervienen y como controlarlas, se armó un esquema general del proceso en un diagrama de flujo y se eligieron diversos sensores y actuadores que permitan realizar el sistema propuesto, además se usó un microcontrolador Arduino para programar la secuencia de control, tras definir todo el sistema se hizo una maqueta simplificada del proceso, además se creó una interfaz para observar las variables del sistema y enviar órdenes
